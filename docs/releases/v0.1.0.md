First version.

- Tray icon shaped like a battery: filled to the charge level, a bolt while charging, a red
  outline while the grid is lost.
- Status window: Now, Energy, Live, Sessions and Events tabs.
- Charge and discharge sessions: how long it took from one charge level to another, and the energy.
- Grid outage detection (experimental, switch it on in Settings → Advanced) with the time left
  on the battery, based on the real drain once it has been measured.
- Desktop and Telegram notifications, each switchable, with thresholds. Critical and normal
  notifications look different. The `/marstek` Telegram command replies with the current status.
- Settings window with explanations on hover, adjustable font size, English and Ukrainian.

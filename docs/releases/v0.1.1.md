Fixes and documentation.

- The battery is found again when it is connected by a network cable. It reported its address
  with extra zeros (like `192.168.01.020`), which Windows cannot use; the app now uses the address
  the reply came from and drops extra zeros from the address in Settings.
- The Now tab no longer says "Grid connected" when it cannot know: with the battery idle and
  nothing on the backup socket it shows `Grid: unknown (battery idle, nothing on backup)`.
- "Battery not responding" now asks to check the home network (Wi-Fi or cable).
- User guide in English and Ukrainian, included in the zip (`docs` folder).
